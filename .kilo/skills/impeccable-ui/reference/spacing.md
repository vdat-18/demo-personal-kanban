# Spacing

## Goals

- Strong grouping
- Easy scanning
- Consistent rhythm between sections

## Rules

- Use spacing to show hierarchy before adding borders or color.
- Related controls should sit close together.
- Separate reading zones from action zones.
- Avoid panels with very heavy padding if the content is lightweight.
- Avoid dense lists with no vertical rhythm.

## In Practice

- Panel headers, bodies, and footers should feel like one system.
- Timeline items should breathe enough to scan quickly.
- Task proposal lists should feel structured, not stacked randomly.
