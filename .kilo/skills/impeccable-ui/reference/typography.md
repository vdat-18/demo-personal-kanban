# Typography

## Goals

- Clear hierarchy
- Comfortable reading
- Strong distinction between UI chrome and document content

## Rules

- Use a consistent scale for page title, section title, panel title, body, helper, and micro label text.
- Headings must feel clearly different from body text, not just slightly larger.
- Helper text should still be readable, never washed out.
- Long-form content like plans and revisions should have generous line-height.
- UI metadata should be compact, but not cramped.

## In Practice

- Planning page title: strong and compact.
- Panel titles: clear but lighter than page title.
- Document views: optimized for reading, not dashboard density.
- Micro labels: use carefully; too many makes the UI feel noisy.
