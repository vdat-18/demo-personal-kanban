# Color And Contrast

## Goals

- Strong readability
- Color used with meaning
- Consistent status semantics

## Rules

- Use color to communicate state, not to decorate every surface.
- Ensure text remains readable on tinted backgrounds.
- Avoid low-contrast helper text.
- Use a calm neutral foundation and reserve saturated color for action or status.
- Keep warning, success, and info states visually distinct.

## In Practice

- Attention panels can use warm color, but text must stay readable.
- Metadata should not disappear into the background.
- Buttons and status labels should communicate priority clearly.
