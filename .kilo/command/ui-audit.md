description: Audit a UI surface using impeccable-ui rules
---
Use the `impeccable-ui` skill, which wraps the vendored upstream `impeccable` repository in `vendor/impeccable`.

Audit the UI in $ARGUMENTS.

Focus on:
- typography hierarchy
- spacing and grouping
- contrast and color semantics
- interaction clarity
- UX writing
- anti-patterns
- responsive risks if visible from the code

Return findings first, ordered by severity.
Do not code unless explicitly requested.
